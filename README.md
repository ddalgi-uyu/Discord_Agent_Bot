# Discord Agent Bot

A collection of AI-powered agents that deliver notifications and utilities via Discord.

## Projects

### 🚗 Parking Reminder
A zero-friction parking recorder with Android widget + Discord bot integration.

- **Quick Park UI**: Tap floor chip → type slot → save. 3 actions, under 5 seconds.
- **Home Screen Widget**: One-tap GPS parking from your Android home screen.
- **Discord Bot**: `/whereiscar` and `/park` commands for recall and recording.

See [`parking-reminder/plan.md`](parking-reminder/plan.md) for full architecture.
